# P0 STUDIO — your Week 1 workspace

This repo is your studio: the place where everything you build in Phase 0 of
[FDE Ready](https://18-139-194-222.sslip.io) lives. It's a real repository with a
real development environment attached. Nothing in here is a simulation.

## Start working (one button, nothing to install)

1. Click the green **Code** button above → **Codespaces** → **Create codespace on main**.
2. Wait ~60 seconds while your machine boots. It's a full Linux computer in the
   cloud with VS Code on top — yours for this course.
3. Open `index.html`. Click the **Show Preview** icon (top-right of the editor)
   to see the page. Edit something. Watch it change.

## Ship it (every push deploys)

**One-time switch first:** in this repo go to **Settings → Pages → Build and
deployment → Source: GitHub Actions**. (GitHub doesn't let the workflow flip
this for you — it's a one-click, once-ever setting.)

After that, every commit pushed to `main` publishes your site to
**GitHub Pages** automatically at:

```
https://<your-username>.github.io/<this-repo-name>/
```

First deploy takes ~1 minute (check the **Actions** tab). That URL is what the
FDE Ready platform verifies — if it's not live, it didn't happen.

## House rules

- Work in the Codespace terminal when a module says so. The terminal is the job.
- Commit early, commit often. Your commit history is part of your portfolio.
- **Stop your codespace** when you're done for the day (Codespaces menu →
  Stop). Your free tier is 120 core-hours/month — plenty, if you don't leave
  the engine running.
